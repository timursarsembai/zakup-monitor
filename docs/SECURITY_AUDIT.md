# Аудит безопасности (2026-11-08)

Уровень пентеста: код целиком (6 направлений) и живой сайт снаружи (без нагрузки,
без SMS, без оплат). Критичных дыр в сайте нет: пароли, сессии, защита от подделки
запросов, права доступа к чужим данным, оплата и вебхук сделаны правильно. Серьёзные
риски — в автономных ИИ-агентах на сервере, в расходе денег на ИИ и SMS и в отсутствии
резервной копии базы.

Статус: ✅ исправлено · ⏳ в работе · 👤 нужно решение или действие владельца.

## Низкие

- Выгрузка Excel: формулы из названий лотов (`=HYPERLINK…`) выполняются у клиента.
- Возврат денег не забирает дни тарифа и неизрасходованные поиски; возврат, пришедший раньше оплаты, теряется.
- Лимит 5 счетов Kaspi в час обходится параллельными запросами.
- Лимит 20 поисков в день обходится параллельными запросами; у модераторов лимита нет.
- Баланс поисков может уйти в минус (списание администратором).
- Вопросы поставщику проверяют ссылку по поискам всех клиентов (видно, что нашли другие).
- Модератор может завести аккаунт на чужой номер телефона.
- Админ видит пароль другого админа при сбросе; сброс себе блокирует аккаунт.
- Подбор текущего пароля в «Сменить пароль» без лимита.
- Пароль: 8 знаков при регистрации, 10 в настройках.
- В журнал попадает введённый логин при неудачном входе (бывает, что туда вставляют пароль).
- Группа клиентов: запись участника не обновляется при перепривязке Telegram.
- ИИ-подбор (`claude -p`) получает в окружении пароль базы и ключ шифрования; запрет внутренних адресов неполный.
- Каждая служба получает все секреты; контейнеры без `cap_drop`/`no-new-privileges`; образы без фиксированных версий.
- Админский бот падает по кругу на одном «плохом» сообщении.
- Настройки ИИ берутся у первого администратора, даже удалённого.
- `/t/event` без лимита — можно накрутить цифры дашборда.

## Проверено и в порядке

- Пароли: scrypt с солью, сравнение за постоянное время, вход не выдаёт, есть ли аккаунт.
- Сессии: случайный токен, в базе только хеш, новый при каждом входе, закрываются при смене пароля; куки HttpOnly, Secure, SameSite=Lax.
- Подделка запросов с чужого сайта: проверка источника на всех изменяющих POST (проверено и снаружи).
- Перенаправление на чужой сайт после входа невозможно; внедрения скриптов (XSS) не найдено — шаблоны экранируют всё, `|safe` нигде нет.
- SQL: все значения параметрами, имена колонок — только из списков.
- Права: все 91 адрес, чужие лоты, подписки, счета, поиски по номеру не открываются; модератор не может админских действий.
- Оплата: подпись вебхука, один раз на событие, сумма сверяется, цена считается на сервере.
- TLS 1.2/1.3, служебные адреса (`/docs`, `/.env`, `/.git`) закрыты, ошибки без внутренностей, база и шлюз слушают только 127.0.0.1, секреты в git не найдены.
